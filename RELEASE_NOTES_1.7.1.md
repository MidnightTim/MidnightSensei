# Midnight Sensei v1.7.1 — Release Notes
**Date:** June 16, 2026

## Overview

Version 1.7.1 is a compatibility update for World of Warcraft patch 12.0.7. No gameplay changes.

---

## TOC Interface Compatibility Update

Updated the addon's declared interface version from `120005` to `120007` to match patch 12.0.7. Without this update, the addon appears as out-of-date in the in-game addon list even though it functions correctly.

No functional changes were made in this release.
